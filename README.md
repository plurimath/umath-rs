# umath Rust raw parser

Local unpublished Rust package using the upstream shared PARG artifact and declared
Rust bindings; no handwritten grammar. `Parser::new()` verifies embedded checksums.

```rust
let parser = umath::Parser::new()?;
let parsed = parser.parse("x+1")?;
println!("{}", parsed.canonical());
# Ok::<(), umath::Error>(())
```

`parse_with_decimal(input, decimal)` accepts `.`, `,`, and `٫`. The native
Parsanol engine uses the immutable source candidate recorded in `UPSTREAM.json`. Unicode preprocessing and stage transforms
are reused from the pinned shared testsuite, with attribution in UPSTREAM.json.
Errors preserve the native error and expose UTF-8 byte offsets relative to the
preprocessed grammar input. Parsed slices reference `parsed_input`; caller offsets
are not inferred after preprocessing. Canonical output includes character offsets.

The default API exposes raw stage trees and bound JSON. Optional `models` uses
75 types and JSON codecs generated by the pinned upstream Lutaml Rust PR #8
generator. `Parser::parse_model(input, decimal)` constructs the typed document,
including UnicodeMath labels; `typed::to_portable_json(model)` writes its declared
portable JSON representation.

`cargo build --features ffi --lib` builds the version-1 stage C ABI described in
`include/umath.h`. Inputs are borrowed UTF-8 buffers; free every returned JSON
buffer once through the same library's `umath_free_json_v1` function.

Typed construction and symbolic/decimal/label cases were exercised locally.
Full typed equivalence, Plurimath facade and math-writer coverage are separate.
The declared portable JSON writer omits empty/nil members, so lossless model
roundtrip and wire idempotence are not guaranteed.

Native refusal offsets use the Rust engine's farthest-error position and may differ
from Ruby's deepest-error selection. Offsets refer to the preprocessed grammar
input; caller-coordinate remapping is not inferred.

`Parser::parse_legacy(input)` and `parse_legacy_with_decimal(input, decimal)`
expose the legacy stage policy. Existing `parse`, `parse_with_decimal` and model
JSON APIs preserve strict native behavior. Legacy errors still refer to
preprocessed input, and slices reference `Parsed::parsed_input`.
UnicodeMath explicitly selects the producer's Parslet execution policy.

CI also replays unicode generation 5 of plurimath/plurimath-testsuite, pinned in
`tests/fixtures/corpus-pin-5.json` by commit, provenance SHA-256 and the expected
row IDs of each boundary. `.github/scripts/extract-corpus.py` checks the pin and
every payload checksum, and `tests/corpus_replay.rs` replays all 747 raw-tree rows
through the legacy raw parser and all 747 typed-model rows through `parse_model`.
Both counts include the 675 rows from the upstream UnicodeMathML tests (MIT,
Noah Doersing 2019; notice and provenance are in the testsuite). Typed rows are
compared as generated Rust models: the expected Ruby model is decoded by the
generated codec, which keeps the declared class of every field but not the Ruby
class names themselves.
